# Women's University Complaint Reporting System

## Project Overview
The Women's University Complaint Reporting System is a software project designed to help students report problems and complaints within the university. The system aims to make reporting easier, faster, and more organized.

## Problem Statement
Students may experience challenges when reporting issues such as poor facilities, water shortages, electricity problems, and other campus-related concerns. A computerized system can help students submit complaints and make it easier to track their progress.

## Objectives
- Identify problems affecting students at Women's University.
- Develop a computerized complaint reporting solution.
- Allow students to submit and manage complaints.
- Apply software engineering principles during development.
- Use Git and GitHub for version control and collaboration.

## Tools Used
- Visual Studio Code
- Git
- GitHub

## Project Management
GitHub Projects will be used to organize tasks, manage the development backlog, and track project progress.
